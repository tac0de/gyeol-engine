# 외부 사용자에게 유용한 공개 베타까지의 범위

확정 방향은 **에이전트 친화적인 웹 기반 2D 게임 엔진**, PC 패키징은 선택 기능입니다. MIT 소스는 이미 공개되어 있습니다. 아래 기준은 '코드 공개'와 별개로, 처음 온 사람이 자기 에이전트와 게임 하나를 완성할 수 있는 공개 베타의 제안 범위입니다. 일정이나 구현 완료를 약속하는 목록이 아닙니다.

## 현재 0.7 범위

- 기존: 결정적 규칙/시간/RNG, inspect/명령 기록/replay, 입력·이미지·음향 수명, 소스 결속 재현/정책 실험 도구, 독립 프로젝트 생성.
- 0.6: 메뉴/플레이/결과 화면 생명주기, 이벤트 정리, 포커스 이동, native 모달, 기본 반응형 DOM UI 구조와 실제 예제.
- 0.6: 웹 기본 설치에서 Electron 제외, 명시적 `desktop:setup` 이후 PC 패키징, 수동 Mac 호환 검사 유지.
- 0.7: 체크포인트·버전형 브라우저 저장·마이그레이션·정상본 복구·실패 재시도 예제. 실제 게임의 계정/서버 저장은 별도입니다.
- 아직: 출시용 에셋 흐름·지원 브라우저 전체·두 번째 독립 게임·신규 사용자 검증은 미완료입니다. 현재는 개발 초기 단계입니다.

## 공개 베타의 필수 구현 묶음과 완료 기준

| 순서 | 필요한 구현 | 외부 사용자 기준의 완료 조건 |
| --- | --- | --- |
| 1. 화면과 UI | 이번 공용 화면/모달/포커스 도구와 메뉴→플레이→결과 예제, 실패/이탈 정리 | 반복 전환·키보드·포인터·좁은 화면에서도 입력 누수/중복 없이 플레이와 replay가 유지됨 |
| 2. 저장과 복구 | 게임이 선택한 상태를 저장하는 버전형 저장 포트, 브라우저 저장 adapter, 마이그레이션/손상 복구, 설정·진행 예제 | 종료/새로고침 후 재개, 이전 버전 변환, 저장 실패/손상 안내와 복구를 실제 검사. 경제·수집 규칙은 게임 소유 |
| 3. 에셋과 기본 표현 | 이미지/atlas/클립·텍스트·음향의 예제와 문서, 로딩/누락/실패/재시도 화면, 취소·해제, 브라우저 오디오 활성화 | 외부 이미지·애니메이션·음향을 바꿔 게임에 연결하고, 잘못된 파일/URL도 원인과 복구 경로가 보임. 플레이/CI에 개인 커널·Aseprite·AI API 키가 필수이지 않음 |
| 4. 입력과 웹 실행 | 지원 범위의 키보드·포인터·터치, 화면 크기/고DPI·포커스/백그라운드 복귀, 공개 static build와 하위 경로 배포 | 동일 게임을 웹 URL에서 실행하고 assets/recording/save가 정상. 지원 브라우저·모바일 범위를 문서와 실제 검사로 제한·명시 |
| 5. 에이전트 제작 루프 | 안정된 create/inspect/check/scenario/replay 명령, 구조화된 오류·명확한 파일 소유, 샘플 AGENTS, 규칙 수정→실패 재현→고침 안내 | 아무 개인 저장소 없이 새 폴더에서 에이전트가 규칙/화면/에셋을 수정하고 오류 원인을 찾아 검사·재현까지 수행. 미지원 기능은 명시적으로 진단 |
| 6. 공개 패키지와 품질 | 설치/업그레이드 경로, 버전·호환 정책, API/튜토리얼, 샘플·기여/보안/이슈 안내, CI와 릴리스 기록 | 깨끗한 환경에서 lockfile 설치·pack 소비·예제 검사 성공, 정확한 지원/미지원 표, 사용자에게 통하는 설치·배포 문서 |

여기서 '에셋 지원'은 범용 렌더러 전체를 만드는 뜻이 아닙니다. 현재 Canvas/DOM host를 활용해 대표 게임에 필요한 sprite/atlas/텍스트/사운드 흐름부터 완성합니다. native AI 생성·Aseprite 연동은 선택 제작 adapter로 두고, 일반 이미지/오디오와 외부 에이전트만으로도 게임을 만들고 배포할 수 있어야 합니다.

## 베타로 부르기 전 통과할 gate

1. **서로 다른 독립 게임 2개:** 예를 들어 퍼즐/턴제 하나와 간단한 실시간 2D 하나. 메뉴·게임·결과·저장·에셋·웹 배포까지 같은 public API로 완성하고, 게임별 복사 코드 때문에 막히는 공용 공백을 해결합니다. 모든 장르 지원을 주장하지 않습니다.
2. **깨끗한 환경과 외부 사용:** 개인 커널·기존 포털·숨은 설정 없이 설치→수정→플레이→검사→replay→웹 배포를 재현합니다. 개발자가 옆에서 경로를 고쳐주지 않아도 외부 사용자 2명이 자기 에이전트로 튜토리얼을 완주하는지 관찰합니다. 이 검증은 아직 하지 않았습니다.
3. **실패와 수명:** 화면 이탈/반복 재시작/모달/저장 손상/에셋 오류/백그라운드 복귀의 결과와 복구를 검사합니다. 긴 판의 recording 한도와 메모리/종료 정책을 명시하고, 한도 초과를 조용히 성공 처리하지 않습니다.
4. **지원 매트릭스:** Chromium만 통과한 결과를 모든 웹 브라우저 지원으로 확대하지 않습니다. Firefox/WebKit, 실제 대상 모바일의 터치/오디오와 접근성·포커스 관찰을 수행하고 지원 범위를 확정합니다. 자동 검사는 사람의 재미·미관 판단과 구분합니다.
5. **공개 사용 계약:** 패키지 이름·배포 방식(현재 tarball)과 업그레이드/변경 로그를 정리하고 API 예제·기여 가이드·오류 보고 절차가 실제 버전과 맞아야 합니다. npm 발행은 별도 결정/실행입니다.

이 gate를 통과한 뒤 '작은 웹 2D 게임을 에이전트와 완성하는 데 유용한 베타'라고 설명할 수 있습니다. API 안정화와 실제 사용자 사용이 쌓이기 전에는 범용 1.0 완성도를 주장하지 않습니다.

## 이번 범위 밖

- PC/Steam·서명·자동 업데이트는 실제 게임 수요가 생기면 진행하는 선택 배포 경로입니다.
- 범용 물리/ECS, 대형 에디터, 3D, 네트워크 대전, 계정·상점·결제는 초기 베타의 필수 범위에 넣지 않습니다.
- 엔진이 모델을 라우팅하거나 스스로 모든 게임을 생성하는 서비스는 만들지 않습니다. 에이전트가 명시적인 소스와 검사 도구를 사용하게 돕습니다.

브라우저 저장/복구는 0.7에 구현했습니다. 다음 대규모 범용 기능을 늘리기 전에 대표 실게임에 필요한 부분을 적용해 효용을 확인하는 것을 추천합니다. [내부 우선·공개 experimental 전략 평가](engine-assessment.md)를 따르되 실제 이관은 별도 결정/작업입니다.
